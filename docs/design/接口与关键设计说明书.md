## 1 通用约定

### 1.1 响应信封

```json
{ "code": 0, "message": "ok", "data": { } }
```

- `code = 0` 表示成功；非 0 时 `data` 为 null 或空，`message` 为可直接展示的中文提示。
- 时间格式 `yyyy-MM-dd HH:mm:ss`（`Asia/Shanghai`）；金额出参为两位小数字符串（如 `"35.00"`）。

### 1.2 鉴权

| 项 | 规则 |
|---|---|
| 令牌 | 登录返回 `data.token`（64 位），同时下发 `Set-Cookie`（HttpOnly、SameSite=Lax） |
| 传递 | `Authorization: Bearer <token>`，或携带同一 Cookie |
| 失效 | 登出、重置密码、过期（默认 72h）、账号封禁后按接口规则拒绝 |
| 未登录 | `1001` / HTTP 401「请先登录」 |

### 1.3 错误码

以 `common/ErrorCode.java` 为准（共 11 个），下表逐条标注**实际抛出方式**与**覆盖场景**，已与源码交叉核对：

| 常量 | code | HTTP | 含义 | 实现方式 / 实际抛出点 | 覆盖的典型场景 | 数据是否改变 |
|---|---|---|---|---|---|---|
| UNAUTHORIZED | 1001 | 401 | 未登录 / 令牌失效 | 过滤器与 service 直接抛（19 处） | 无令牌、令牌过期、登出后重放 | 否 |
| FORBIDDEN | 1003 | 403 | 角色或对象归属无权 | `BizException.permission()`（27 处） | 非本人、非成交当事人、非管理员 | 否 |
| ACCOUNT_BANNED | 1004 | 403 | 账号封禁 | 直接抛（3 处） | 封禁后发布 / 下单 / 私信 | 否 |
| ADMIN_ONLY | 1005 | 403 | 仅管理员可访问 | **当前代码未使用（0 处）** | 管理端统一走 `permission()` → 1003 | 否 |
| ACCOUNT_LOCKED | 1006 | 429 | 登录锁定 | `AuthService`（1 处） | 连续 5 次密码错误锁 15 分钟 | 仅失败计数与锁定时间 |
| VALIDATION_FAILED | 2001 | 422 | 参数校验失败 | `BizException.validate()`（61 处）+ Bean Validation | 字段缺失、格式、长度、禁售词、站外导流 | 否 |
| STATE_REJECTED | 3001 | 409 | 业务状态不支持 | `BizException.state()`（57 处） | 商品非在售、成交已撤销、**重复举报**、**评价期限已过**、一单一评 | 否 |
| NOT_FOUND | 3002 | 404 | 对象不存在 | `notFound()`（28 处） | 商品 / 成交 / 评价 / 学生不存在或已删除 | 否 |
| CONFLICT | 3003 | 409 | 冲突 | `conflict()`（4 处）+ `DuplicateKeyException` 兜底 | 邮箱已注册、学号被占用、唯一索引冲突 | 否 |
| RATE_LIMITED | 4001 | 429 | 频控 | `rateLimit()`（2 处） | 验证码 60 秒 / 24 小时频控 | 否 |
| INTERNAL | 5000 | 500 | 未预期异常 | `GlobalExceptionHandler` 兜底（4 处） | 未捕获异常 | 事务回滚 |

**交叉核对结论（2026-11-14）**

1. `ADMIN_ONLY(1005)` 已定义但**从未抛出**：管理端接口靠 `PermissionService` 抛 `permission()` → 1003。二选一：删掉该码，或管理端改抛 1005（改动面大，暂保留并在此登记）。
2. **「重复举报」与「评价期限已过」没有独立错误码**，都走 3001（`ReportService:103`、`ReviewService:73`），前端只能靠 `message` 区分。若要单列，建议新增 3004（重复举报）/ 3005（评价期限已过），需同步改 service 与前端分支——**尚未实现**。
3. 3003 有两个来源：service 显式 `conflict()`（4 处）与数据库唯一约束的 `DuplicateKeyException` 兜底；后者是并发下的最后一道，前端应统一按 409 处理。
4. 计数口径：`BizException.<helper>(` 在 `service/` 中的出现次数，统计于 2026-11-14。

| 项目 | 内容 |
|---|---|
| 接口编号/名称 | API-02 / 学生注册 |
| 需求与决策依据 | UC-01 主 3–4、AT-01；ADR-003；Q-01（密码强度） |
| 方法与路径 | `POST /api/auth/register` |
| 调用者及权限 | 游客；无需令牌 |
| 请求 | 体：`email` string 必填（邮箱格式，全局唯一）；`code` string 必填（6 位数字）；`nickname` string 必填（1–20，非纯空白）；`realName` string 必填（1–20，非纯空白）；`password` string 必填（强度见 Q-01）；`phone` string 可选（11 位，可空）；`agree` boolean 必填且必须为 true |
| 成功响应 | 200；`code=0`；`message="注册成功，请提交学生证核验"`；`data` 为本人视图：`id,email,studentNo(空),nickname,realName,phone,dorm(空),certStatus="未提交",accountStatus="正常",creditScore=100,reviewCount=0,verifiedDisputeCount=0,resubmitCount=0,registeredAt` |
| 失败响应 | 格式/必填/验证码错 → `2001`（原样返回校验文案）；邮箱占用 → `3003`「该邮箱已注册，请直接登录或找回密码」；验证码请求过频 → `4001`。失败均**不创建账号** |
| 前置与后置 | 前置：邮箱未被占用、验证码有效且未使用。后置：新增 1 名学生（未提交/正常/100 分），验证码标记已用 |
| 并发与幂等 | 同一邮箱并发注册：由唯一键 `uk_student_email` 兜底，仅 1 个成功，其余 `3003`；重复提交同一验证码：第二次因已用而失败 |
| 事务 | 创建学生 + 标记验证码已用 + 写审计，同一事务；失败整体回滚 |
| 隐私 | 响应不含密码哈希、验证码；日志与审计不记录验证码明文 |
| 测试关联 | TC-001、TC-002、TC-003、TC-004、TC-005、TC-006、BB-001～BB-004 |
| 确认 | 待填（后端提供方 / 前端调用方 / 复核人 / 版本） |

### API-03 登录

| 项目 | 内容 |
|---|---|
| 接口编号/名称 | API-03 / 学生登录 |
| 需求与决策依据 | UC-01 主 6、辅 A/E、NFR-05；ADR-003 |
| 方法与路径 | `POST /api/auth/login` |
| 调用者及权限 | 游客 |
| 请求 | 体：`email` string 必填；`password` string 必填 |
| 成功响应 | 200；`message="登录成功"`；`Set-Cookie`（HttpOnly、SameSite=Lax）；`data.token`（64 位）、`data.student`（本人视图）、`data.restrictedNotice`（受限时的提示，可空） |
| 失败响应 | 凭据错误 → `1001`「邮箱或密码不正确」；封禁 → `1004`「账号已封禁，不可发布与下单」；锁定 → `1006`「账号已暂时锁定，请稍后重试」；参数缺失 → `2001`。失败均不建立会话 |
| 前置与后置 | 前置：账号存在且未锁定（或锁定已到期）。后置：新增会话记录、失败计数清零、写登录成功通知（Q-06） |

## 3 关键详细设计

### 3.1 商品状态机与接口映射

| 转换 | 触发 | 接口 | 目标 | 拒绝条件 |
|---|---|---|---|---|
| ST-01 | 卖家发布 | API-18 | 待审核 | 资格/字段不合法 |
| ST-02 | 审核通过 | API-28 | 在售 | 非待审核 |
| ST-03 | 审核拒绝 | API-29 | 已下架（审核不通过） | 缺类目编号 |
| ST-04 | 卖家撤回 | API-20 | 已下架（卖家撤回） | 非待审核 |
| ST-05 | 买家下单 | API-34 | 已售出 | 非在售/自购/信用不足 |
| ST-06 | 卖家下架 | API-21 | 已下架（卖家主动下架） | 非在售 |
| ST-07 | 管理员强制下架 | API-30 | 已下架（管理员违规下架） | 已售出/证据缺失 |
| ST-08 | 重新提交 | API-23 | 待审核 | 下架原因不属两种（Q-02） |
| ST-09 | 撤销违规处置 | API-31 | 在售 | 非「管理员违规下架」 |
| ST-10 | 单方撤销成交 | API-37 | 在售 | 已评价/非当事人/已撤销 |
| ST-11 | 撤销且卖家封禁 | API-37 | 已下架（撤销后不可交易） | 同上 |
| ST-12 | 在售编辑 | API-19 | 待审核 | 已售出/非本人 |
| ST-13 | 封禁联动 | API-66 | 已下架（管理员违规下架） | 已售出不受影响 |

> 不存在的转换：`已售出→待审核`、`已下架→已售出`、`待审核→已售出`。任何接口都不得产生这些边。

### 3.2 数据库不变量（兜底，不依赖 service 判断）

| 不变量 | 实现 |
|---|---|
| 邮箱/学号唯一 | `uk_student_email`、`uk_student_no` |
| 同一学生同时最多 1 条待审核验 | `uk_cert_pending(pending_sid)` 生成列 |
| 已下架 ⇔ 有下架原因 | `ck_product_reason` |
| 价格 >0 且 ≤50000 | `ck_product_price` |
| 同一商品最多 1 条有效成交 | `uk_order_one_valid(valid_product_id)` 生成列 |
| 买家 ≠ 卖家 | `ck_order_self` |
| 一单一评 | `uk_review_order_reviewer` |
| 同一对象只举报一次 | `uk_report_reporter(reporter_id,target_type,target_key)` |
| 信用流水幂等 | `uk_credit_source(source_key)` |
| 信用分 0～150、事件与符号匹配 | `ck_student_credit`、`ck_credit_sign` |

### 3.3 事务边界

| 动作 | 同一事务内 | 事务外 | 失败处理 |
|---|---|---|---|
| 下单 | 订单插入 + 商品条件更新 + 通知 | 无 | 整体回滚，商品仍在售 |
| 撤销 | 订单状态/撤销字段 + 商品状态 + 通知 | 无 | 整体回滚 |
| 判定 | 判定字段 + 信用分 + 信用记录 + 通知 | 无 | 整体回滚（Q-05 与超时分支需特别验证） |
| 封禁 | 账号状态 + 批量下架 + 通知 + 审计 | 无 | 整体回滚，不得只封不禁 |
| 审核 | 商品状态 + 审核信息 + 通知 + 审计 | 图片文件 | 状态回滚，文件可能残留（已知风险） |

### 3.4 并发与锁顺序

- 当前实现**不加显式行锁**，依赖「条件更新 + 唯一索引」：`UPDATE ... WHERE status=?` 受影响行数为 0 即视为竞争失败，返回 `3001`。
- 若后续引入 `SELECT ... FOR UPDATE`，统一按 **product → order → student** 顺序加锁，禁止反向，避免死锁。
- 并发对与期望见 SRS §5.5 第 7 条（11 组），验证方式见《分阶段实现与测试计划》TASK-03/06。

### 3.5 超时、重试与补偿

| 场景 | 策略 |
|---|---|
| 邮件发送失败 | 验证码记录保留但提示失败；用户可重新获取（受 60 秒/24h 频控）；不做自动重试 |
| 定时任务 | 幂等（`uk_credit_source`）；重复执行不重复扣分；失败下一轮补跑 |
| 图片落盘失败 | 事务回滚，提示重试；已落盘文件由运维清理（已知风险，未自动化） |
| 客户端断网重发 | 下单重复提交返回同一订单（设计上幂等）；私信失败不落库、不显示已发送 |

### 3.6 异常恢复

- 所有业务异常经 `GlobalExceptionHandler` 映射为统一信封；未预期异常统一 `5000`，事务回滚。
- 约束冲突（`UNIQUE`）映射为 `3003`；状态条件不满足映射为 `3001`。
- 恢复原则：**先判责再修**——实现不符修实现；测试预期错误需依据与人工批准后修测试；需求冲突重开 Q。

### 3.7 隐私与日志禁令

| 数据 | 允许出现的位置 | 禁止 |
|---|---|---|
| 手机号、宿舍地址 | 本人视图、管理员必要场景 | 他人视图、商品/评价/订单/通知、日志、导出 |
| 学生证图片 | 本人提交回显、审核管理员专用接口 | 列表、通知、日志、审计正文、导出 |
| 密码 | 仅哈希入库 | 任何响应、日志、审计 |
| 验证码 | 仅哈希入库 | 日志、审计、错误提示 |
| 令牌 | 响应与请求头 | 日志明文、URL 参数 |
