# 交易与应用正向测试用例

> 版本：SRS V2.1  
> 生成日期：2026-11-26  
> 生成依据：`docs/requirements/SRS.md` 的业务目标、UC-01～UC-18、UC-29～UC-34、BR-01～BR-22、权限矩阵、状态模型和 NFR。  
> 本文件从需求正向设计测试场景，未从现有测试类反推。现有测试类仅可作为实现覆盖检查依据。

## 一、测试范围和共同约定

平台只负责校内学生身份、商品信息、成交登记、评价、信用、举报和站内私信。平台不测试支付、退款、物流、交付确认、收货确认和线下实物事实。

| 测试角色 | 说明 |
|---|---|
| 学生-未认证 | 可注册、登录、浏览，不能发布和下单 |
| 学生-待审核 | 已提交学生证，等待管理员审核 |
| 学生-已认证 | 可发布、下单、收藏、评价和私信 |
| 学生-已驳回 | 可按规则重新提交核验，不能发布和下单 |
| 学生-受限/封禁 | 受限账号按限制项处理，封禁账号不得登录和交易 |
| 管理员 | 可登录后台，审核认证、审核商品、处理举报和查看审计 |

## 三、状态转换验收

| 编号 | 状态模型 | 触发 | 必须验证 |
|---|---|---|---|
| ST-001 | 商品 | 发布 | 无论内容是否合规，初始状态均为待审核 |
| ST-002 | 商品 | 管理员通过审核 | 待审核→在售 |
| ST-003 | 商品 | 管理员拒绝、卖家下架或违规处置 | 待审核/在售→已下架，原因可追溯 |
| ST-004 | 商品 | 正常下单 | 在售→已售出 |
| ST-005 | 商品 | 有效撤销且卖家正常 | 已售出→在售 |
| ST-006 | 商品 | 有效撤销且卖家已封禁 | 已售出→已下架 |
| ST-007 | 学生认证 | 注册 | 未提交 |
| ST-008 | 学生认证 | 提交申请 | 未提交/已驳回→待审核 |
| ST-009 | 学生认证 | 审核通过/驳回 | 待审核→已认证/已驳回 |
| ST-010 | 交易 | 下单 | 生成有效成交记录，平台不生成支付或交付状态 |
