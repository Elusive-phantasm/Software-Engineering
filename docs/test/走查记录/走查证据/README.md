## 五、复核结论与撤回记录

1. **A.6 的全部「通过」必须以第二节所列截图中的可见内容为依据**；本报告已不再引用任何源码检索结论。
2. **前一稿的错误及撤回**：前一稿把墨刀旧版静态 HTML 导出件当作交付件核对，由此把 PV-03-1、PV-03-2 判为「失败」，并判定「后台无举报处置」「无发布商品页」「详情页无成色字段」。经核对 Figma 设计稿原始截图，**上述四项结论均不成立，已全部撤回并更正**——订单结果页标注「八种状态 · 非同时生效」且 8 个状态齐备，审核工作台有「举报处理 2」页签，发布商品页完整存在，商品详情页有独立「成色 9成新」字段。详见 A.7 **V-28**、**V-31**、**V-33**。
3. **业务层无任何证据**：状态持久化、权限拦截、数据写入均未验证；A 报告 A.6 也没有作出此类结论。
4. **原型本身落后于需求**：Figma 设计稿的业务方案仍为 v1.1（学校统一身份认证、保留自提点、审核工作台无学生证核验），与 V1.2.1 存在三处实质偏差，记为 **V-46**、**V-47**，需过振宇更新原型。

> **不作出的声明**：本目录不包含任何业务层（状态持久化、权限拦截、数据库写入）的验证证据。
