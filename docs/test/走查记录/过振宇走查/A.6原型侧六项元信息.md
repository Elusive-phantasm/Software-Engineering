## ☐ A.6 原型侧六项元信息

原型是**静态 HTML**（动态版因墨刀额度耗尽无法导出）。`checkout.html` 里 `localStorage` 和 `sessionStorage` 都是 **0** 次，`submitOrder()` 只做四件事：阻止提交 → 校验协议勾选 → 生成随机单号 `OD-20261021-NNNN` → 填进结果区。

| 栏目 | 内容 |
|---|---|
| 原型名称与版本 | 校园二手交易与物品流转平台 · 可点击原型 · 静态 HTML 版（4 页） |
| 原型入口 / 打开环境 | `原型-可自行修改\home.html`；本机 Chrome / Edge 直接打开，无需服务器 |
| 本次走查的页面 | 首页 `home.html`、商品详情 `detail.html`、下单与订单结果 `checkout.html`、后台审核 `admin.html` |
| 使用的模拟数据或接口及其范围 | 仅前端内置示例数据（4 页各带静态商品数组 + `images/` 12 张图）；**无接口、无后端、无本地存储**，页面之间不传递状态 |
| 未实现或未验证的功能清单 | 见下方清单 |
| AI 生成原型痕迹与人工修改说明 | 在墨刀中用 AI 生成 4 个页面初稿；后改为静态 HTML 导出（墨刀动态导出额度不足），手工把 CDN 引用改为公共 CDN、把 `modao.cc` 资源链接改为本地相对路径、去掉 `?render_html=true`，使原型可离线直接打开 |

**「实际结果」：**

| 情况 | 结果 |
|---|---|
| 页面层做到了 | **通过**，仅页面流程走查 |
| 业务层（状态真变了 / 数据真存了 / 权限真拦了） | **未验证**，静态原型无状态持久化 |
