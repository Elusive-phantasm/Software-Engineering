# 安全与配置整改记录（2026-11-26）

> 范围：演示工具收口、口令收口、Java 版本统一、部署运维文档补写、错误回显收口。
> **未改动任何需求文档的要求原文**；业务行为除「开发接口访问控制」外未改。
> 基线：分支 `codex/return-approval-requirement`，起点提交 `adae882`。

## 1. 改了什么

### 1.1 演示工具 `/api/dev/**` 收口

| 文件 | 改动 |
|---|---|
| `backend/src/main/java/com/campus/trade/config/SecurityConfig.java` | `/api/dev/**` 从 `permitAll` 改为 `hasRole("ADMIN")` |
| `backend/src/main/java/com/campus/trade/controller/DevController.java` | `GET /api/dev/state` 补 `assertEnabled()`；`assertEnabled()` 追加管理员身份检查（纵深防御） |
| `backend/src/main/resources/application.yml` | `app.features.enable-dev-tools` 默认值 `true` → `false`，并改由 `APP_ENABLE_DEV_TOOLS` 控制 |
| `backend/src/main/java/com/campus/trade/config/AppProperties.java` | `enableDevTools` 字段默认值同步改为 `false` |
| `frontend/src/views/admin/Dashboard.vue` | 探到 `/api/dev/state` 不可用时隐藏演示面板，不再阻塞看板加载、不再弹全局错误 |
| `frontend/src/api/http.js`、`frontend/src/api/index.js` | 新增 `silent` 选项，供可选的可用性探测使用 |

### 1.2 演示口令与管理员初始口令收口

| 文件 | 改动 |
|---|---|
| `backend/src/main/java/com/campus/trade/seed/DataSeeder.java` | 删除写死的 `Test@12345` / `Admin@12345`；改为「环境变量 > 上次生成的凭据文件 > 随机生成（14 位）」；随机口令写入 `app.seed.credentials-file`，日志只打印路径；新增 `app.seed.enabled` 总开关 |
| `backend/src/main/resources/application.yml` | 新增 `app.seed.*`；`app.env`（`APP_ENV`） |
| `backend/src/main/java/com/campus/trade/config/AppProperties.java` | 新增 `env` 与 `Seed` 配置组 |
| `backend/src/main/java/com/campus/trade/config/StartupGuard.java`（新增） | `APP_ENV` 非 dev/test 时**阻断式**校验：开发工具必须关闭、演示数据必须关闭、数据库/演示口令不得等于仓库内公开过的演示口令；不满足即抛异常退出，早于对外服务 |
| `frontend/src/views/student/Login.vue`、`frontend/src/views/admin/AdminLogin.vue` | 删除预填口令与账号；改为可选 `VITE_DEMO_*` 注入；占位符不再印演示账号 |
| `frontend/.env.example`、`backend/.env.example`（新增） | 环境变量清单，不含真实值 |
| `.gitignore` | 忽略 `.env*`、`seed-credentials.txt` |
| `一键启动.bat`、`启动数据库.bat` | 控制台不再打印演示口令；建库提示改为「口令请自行设置 + 用 `DB_PASSWORD` 传入」 |
| `tools/smoke.mjs`、`tools/e2e.mjs`、`tools/bench.mjs` | 改为从环境变量/凭据文件读取口令（`tools/demo-accounts.mjs`，新增）；`/api/dev/reset` 改为带管理员令牌，且重置后重新登录 |

> 敏感信息：本次验证中生成的口令只写入临时目录并已删除，未进入仓库、日志或本文档。

### 2.4 生产环境启动校验

```powershell
# 不安全组合：APP_ENV=prod 且 开发工具开、演示数据开、用演示数据库口令
java -jar target/campus-trade-backend-1.0.0.jar --server.port=18083
```

结果：进程退出码 **1**，日志：

```
Caused by: java.lang.IllegalStateException: 生产环境配置校验未通过：
 - app.features.enable-dev-tools 仍为 true：生产环境必须关闭（APP_ENABLE_DEV_TOOLS=false）
 - app.seed.enabled 仍为 true：生产环境必须关闭演示数据初始化（APP_SEED_ENABLED=false）
 - spring.datasource.password（数据库口令） 使用了仓库内公开的演示口令，必须改为环境变量注入的独立口令
```

且该异常发生在 **Tomcat 开始服务之前**（`startupGuard` Bean 初始化阶段）。

```powershell
# 安全组合：APP_ENV=prod + 开发工具关 + 演示数据关 + 独立 DB 口令
java -jar target/campus-trade-backend-1.0.0.jar --server.port=18086
```

结果：正常启动（`Started CampusTradeApplication`），此时：

| 路径 | 状态 |
|---|---|
| `/api/dev/state` | 401 |
| `/api/products` | 200 |
| `/api/nonexistent-endpoint` | 401，响应体仅 `{"code":1001,"message":"请先登录"}`（无堆栈、无内部细节） |

再以 `APP_ENABLE_API_DOCS=false` 启动：

| 路径 | 状态 |
|---|---|
| `/v3/api-docs` | 404 |
| `/swagger-ui.html` | 404 |

### 2.5 首次启动口令生成与重置稳定性

- 空库首次启动：日志出现「开始初始化演示数据…」「已生成演示口令并写入 …\seed-credentials.txt」，
