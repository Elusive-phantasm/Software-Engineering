## 2. 业务规则（22 条）

| 编号 | 规则要点 | 实现位置 | 保障方式 |
|---|---|---|---|
| BR-01 | 核验后才可发布/下单，禁止自购 | `PermissionService#requirePublishRights/requireOrderRights`、`OrderService#create` | 服务层校验 |
| BR-02 | 在售上限 5 件 | `ProductService#create/resubmit` | 服务层计数 |
| BR-03 | 发布即待审核，审核通过才在售 | `ProductService#create/approve/reject` | `products.status` 约束 |
| BR-04 | 禁售清单闭集 + 举报须核实 | `constant/ForbiddenCategories`、`ReportService` | 18 类闭集、驳回必填类目编号 |
| BR-05 | 价格 >0 且 ≤50000，最多 2 位小数 | `ProductService#parsePrice` | `BigDecimal` + 库内 CHECK |
| BR-06 | 下单即成交、原子、唯一 | `OrderService#create` | 条件更新 + `uk_order_one_valid` |
| BR-07 | 平台不碰钱货 | 全库无支付/交付字段 | 结构性保证 |
| BR-08 | 仅有效成交双方可评、一次、7 天 | `ReviewService#submit` | `uk_review_order_reviewer` + 时间校验 |
| BR-09 | 下架/删除权限与软删除 | `ProductService#takeDown/delete` | 状态前置校验 |
| BR-10 | 封禁连带下架 | `BanService#ban` | 同一事务内批量下架 |
| BR-11 | 只展示在售、收藏唯一 | `ProductService#list`、`favorites` 唯一键 | 查询条件 + 唯一索引 |
| BR-12 | 成交统计去重 | `AdminService#dashboard` | 按有效订单聚合 |
| BR-13 | 信用分 0～150、60/40 阈值 | `CreditService#apply`、`PermissionService` | 截断 + 阈值判断 |
| BR-14 | 四类信用事件 | `CreditService`、`ReviewService`、`ReportService`、`SchedulerService` | 幂等键 `source_key` |
| BR-15 | 主动通知清单 | `NotificationService` | 各业务点触发 |
| BR-16 | 7 天提交、24 小时审核 | `SchedulerService#certSubmitReminder/certReviewTimeout` | 只提醒不自动通过 |
| BR-17 | 重提上限 3 次 | `VerificationService#submit` | `resubmit_count` + CHECK 0～3 |
| BR-18 | 伪造必须封禁 | `VerificationService#reject(forgery)`、`revokeCertification` | 调用 `BanService` |
| BR-19 | 认证状态与账号状态分离 | `BanService`、`VerificationService` | 分字段更新 |
| BR-20 | 私信范围与准入 | `MessageService#send` | 参与方/认证/绑定商品校验 |
| BR-21 | 撤销单方即时生效 + 7 天判定 | `OrderService#cancel/judge`、`SchedulerService#cancelJudgeTimeout` | 条件更新 + 幂等扣分 |
| BR-22 | 编辑重审 | `ProductService#update` | 在售→待审核、刷新发布时间 |

## 3. 状态转换（ST-01～ST-13 / AT-01～AT-08）

| 编号 | 触发 | 实现 |
|---|---|---|
| ST-01 | 发布 → 待审核 | `ProductService#create` |
| ST-02 | 审核通过 → 在售 | `ProductService#approve` |
| ST-03 | 审核拒绝 → 已下架（审核不通过） | `ProductService#reject` |
| ST-04 | 卖家撤回 → 已下架（卖家撤回） | `ProductService#withdraw` |
| ST-05 | 下单 → 已售出 + 创建订单 | `OrderService#create` |
| ST-06 | 卖家下架 → 已下架（卖家主动下架） | `ProductService#takeDown` |
| ST-07 | 管理员违规下架 | `ProductService#forceOff`、`ReportService#handle` |
| ST-08 | 已下架 → 待审核（限两种原因） | `ProductService#resubmit` |
| ST-09 | 撤销违规处置 → 在售 | `ProductService#restore` |
| ST-10 | 撤销成交 → 在售 | `OrderService#cancel` |
| ST-11 | 撤销时卖家已封禁 → 已下架（撤销后不可交易） | `OrderService#cancel` |
| ST-12 | 在售编辑 → 待审核 | `ProductService#update` |
| ST-13 | 封禁联动下架 | `BanService#ban` |
| AT-01～05 | 注册/提交/通过/驳回/重提 | `VerificationService` |
| AT-06 | 审核超 24 小时：状态保持 + 提醒 | `SchedulerService#certReviewTimeout` |
| AT-07 | 注册满 7 天未提交：状态保持 + 每日提醒 | `SchedulerService#certSubmitReminder` |
| AT-08 | 事后核实伪造 → 已驳回 + 封禁 + 下架 | `VerificationService#revokeCertification` |

## 5. 需求内部矛盾与本项目的处理

| 冲突 | 出处 | 处理 |
|---|---|---|
| 「已售出」撤销是双方合意还是单方 | §7.1/§7.2 vs BR-21/UC-31 | 按 BR-21 实现**单方即时生效** |
| 举报对象只能是商品？ | §6.3 vs BR-04/UC-12 | 按 BR-04 支持**商品或学生**两种 |
| 「卖家主动下架」能否重提 | UC-17 vs ST-08 | 按 ST-08 封闭集：**不可重提**，只能删除后重发 |
| 消息类型六值缺「登录成功」 | §6.2.1 vs BR-15 | 扩展第 7 值 `账号`（可通过开关关闭） |
| 举报成立是否必然扣分 | BR-14 ② vs UC-13 处置手段 | 按 **BR-14 ② 无条件 −10** 实现 |
