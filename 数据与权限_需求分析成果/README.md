## 打开与编辑类图

在 diagrams.net 或 draw.io 桌面版选择“文件 → 从以下位置打开 → 设备”，打开 `.drawio`。这是标准未压缩 mxfile XML，类框、属性、连接线和文字均可编辑。文件仅一页，分交易与分类、评价与信用、举报与管理员三个分区；“引用”框为同名类的重复显示，以减少连线交叉。完整定义为七个核心类加最小管理员概念类，共八类。

线上的数量标记均可编辑；因初稿使用固定位置的文字，移动类框时需同步移动对应的关联名和多重性标记。图中均为 UML 实线关联，用文字标记待确认内容。修改后以 `.drawio` 为最终图源，并重新导出 PNG，保持字典与图一致。

PNG 为相同模型和几何坐标生成的高清静态图（4200×3750 像素），可直接阅读或插入 Word。已执行的文件检查和未执行的编辑器／系统测试详见一致性检查报告；未以 XML 检查冒充 diagrams.net 实际打开验证。
