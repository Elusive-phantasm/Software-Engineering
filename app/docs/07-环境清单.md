# 环境清单

> 项目：拾光二手 · 校园二手交易平台（依据《需求规格说明书 V2.1》实现）
> 本文给出**开发与验证机的实测环境**、**可部署的最低/推荐环境**、依赖清单、端口与磁盘占用，以及一份"已验证 / 未验证"的诚实矩阵。
> 文中所有版本号与体积均为本机实测值，不是估计。

---

## 1. 硬件环境

| 项目 | 开发/验证机（实测） | 最低要求 | 推荐 |
|---|---|---|---|
| CPU | 16 逻辑核 | 1 核（x86_64 / ARM64） | 2 核以上 |
| 内存 | 系统可用内存充足（本项目服务进程常驻约 170 MB，见 §7） | 2 GB | 4 GB |
| 磁盘可用空间 | 代码 ~0.6 MB + 依赖约 20 MB（含仅测试用的 jsdom）+ 运行数据 ~5 MB | 300 MB | 1 GB（留出日志与图片增长） |
| 网络 | 仅**首次安装依赖**与**真实发信**时需要；运行期可完全离线 | 同左 | 同左 |
| 显示 | 任意；浏览器窗口建议 ≥ 1280×800 | 1024×768 | 1440×900 以上 |

> 这是一套**纯软件**系统：不涉及任何硬件设备、传感器、读卡器或校园网专用设备。学生证核验是"上传照片 + 管理员人工比对"，不需要证件阅读器。

## 3. 依赖清单

### 3.1 直接依赖：2 个（1 生产 + 1 仅测试）

| 包 | 类型 | 版本（实测安装） | 用途 | 是否含原生模块（需编译） |
|---|---|---|---|---|
| `express` | **生产依赖** | 4.22.3（`package.json` 声明 `^4.21.2`） | HTTP 路由、静态资源、请求体解析 | 否，纯 JavaScript |
| `jsdom` | **开发依赖** | 31.0.0（`devDependencies`） | 仅 `npm run test:ui` 用：在 Node 里真实执行 `student.js` / `admin.js`，断言页面真的渲染出内容 | 否 |

> `jsdom` 不参与运行：`npm start` 只加载 `express`。若只部署不跑测试，可 `npm install --omit=dev` 把依赖压到 2.3 MB / 67 个包。
> 它存在的原因见 `docs/04-验收测试与场景走查手册.md` §1 第 5 条：接口测试全绿但前端渲染层有 bug 时，只有真实执行前端才能发现。

### 3.2 传递依赖

| 项目 | 实测值 |
|---|---|
| `node_modules` 包数量 | **94 个**（express 生产依赖树 + jsdom 测试依赖树） |
| `node_modules` 体积 | **约 20 MB / 2,082 个文件**（其中 jsdom 及依赖约 17 MB，**仅用于前端渲染测试，运行系统不需要**） |
| 需要本地编译的包 | **0 个**（因此**不需要** Visual Studio Build Tools / Python 编译环境 / node-gyp） |
| 数据库驱动 | **无第三方依赖**，使用 Node 内置 `node:sqlite` |
| 前端框架 | **无**（原生 ES Module + 手写 CSS，零构建、零 CDN） |

### 3.3 为什么没有其它依赖

| 常见依赖 | 本项目做法 |
|---|---|
| MySQL / PostgreSQL 驱动 | 用 Node 内置 `node:sqlite`，单文件数据库 |
| ORM（Sequelize / Prisma） | 手写 SQL，把约束直接写进 `schema.sql` |
| 密码库（bcrypt） | 用内置 `crypto.scryptSync` |
| 会话/鉴权库（passport、JWT） | 自实现令牌 + Cookie，库里只存 SHA-256 |
| 邮件库（nodemailer） | 自实现 SMTP 客户端（`net` / `tls`） |
| 前端框架与打包器（Vue/React/Vite/Webpack） | 原生 ES Module，浏览器直接加载 |
| CSS 框架（Tailwind）与图标 CDN | 手写 CSS（`public/assets/app.css`）+ 内联 SVG 图标 |

## 4. 端口与网络

| 端口 | 方向 | 用途 | 是否必需 |
|---|---|---|---|
| **3081** | 入站（本机） | HTTP 服务：学生端 `/`、管理端 `/admin`、接口 `/api/**` | 必需（可改） |
| 465 / 587 | 出站 | 真实 SMTP 发信（`transport=smtp` 时） | 可选 |
| — | 入站 | 无其它端口；不监听数据库端口（SQLite 是文件） | — |

改端口：`config/default.json` → `server.port`，或设环境变量 `PORT`（`set PORT=3082 && npm start`）。

服务默认只绑定 `127.0.0.1`（`server.host`），**同一局域网其它机器访问不到**。需要对外演示时改为 `0.0.0.0` 或用反向代理。

## 6. 外部服务依赖

| 服务 | 是否必需 | 缺省行为 | 影响范围 |
|---|---|---|---|
| **SMTP 邮件服务** | **可选** | `transport=local`：验证码写入 `data/mailbox.jsonl`，可在学生端右下角扳手面板查看 | 仅影响"验证码是否真的发到邮箱"；注册、找回密码、频控、一次性、错误作废等规则**全部照常生效** |

> 结论：**这是本项目唯一的外部服务依赖，且不是必需项**——不配 SMTP 也能完整演示与验收。

## 10. 环境自检（30 秒）

```powershell
cd D:\software-engineering\Software-Engineering\app

node -v                      # 必须 ≥ v22.5.0
npm ls --depth=0             # 应只列出 express
node -e "require('node:sqlite'); console.log('node:sqlite OK')"

# 服务可用则跑一致性自检
node --no-warnings scripts\check-api-paths.mjs        # 前端调用路径是否都在后端路由表
node --no-warnings scripts\check-server-authority.mjs # 后端是否真的拦住越权请求
```

`node:sqlite` 自检若打印 `ExperimentalWarning`，属正常提示（22.x 仍标记 experimental），`npm start` 已用 `--no-warnings` 屏蔽。

## 11. 不同操作系统的启动方式

| 系统 | 启动 | 安装 | 灌数据 |
|---|---|---|---|
| Windows（推荐） | 双击 `启动.bat`，或 `npm start` | `npm install --cache ./.npm-cache` | `npm run seed` |
| Windows CMD | `npm start` | 同上 | 同上 |
| Linux / macOS | `npm start` | `npm install --cache ./.npm-cache` | `npm run seed` |

> 为什么带 `--cache ./.npm-cache`：在受限环境（目录权限收紧、或全局缓存目录不可写）下，npm 写默认缓存会报
> `EPERM / error writing to the directory`。把缓存指到项目内即可绕过，且该目录已被 `.gitignore` 忽略。
